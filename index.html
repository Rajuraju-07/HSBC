Job Summary

HSBC is hiring Data Insights Developers to support its digital transformation initiatives. The role combines Data Engineering, Data Analytics, Full Stack Development, Data Visualization and Cloud technologies to build applications that deliver business insights across global banking operations.

Educational Qualification

  • B.E. / B.Tech / M.E. / M.Tech / MCA / M.Sc or related degree.
  • Eligible Batch: 2024 / 2025 / 2026.
  • 0–2 years of relevant experience.
  • Fresh graduates with strong programming and analytical skills are encouraged to apply.

Key Responsibilities

  • Develop and optimize data models for business analytics.
  • Perform ETL processes using Google BigQuery.
  • Analyze and manipulate datasets using Python and Pandas.
  • Develop full-stack web applications using Django or Flask.
  • Create responsive interfaces using HTML, CSS and JavaScript.
  • Deploy applications using Docker, Kubernetes and cloud platforms.
  • Build dashboards, reports and data visualizations for stakeholders.
  • Collaborate with business teams and deliver end-to-end solutions.

Required Skills

  • Python Programming

  • HTML5, CSS3 & JavaScript
  • Docker & Kubernetes
  • Data Visualization & Storytelling
  • Git & DevOps Basics
  • Problem Solving & Communication Skills

Preferred Skills

  • API Development
